# דנה — רשימת קבלה אחת

מסמך חי. מצב אפשרי לכל פריט:
**עובד ונבדק** (נבדק דרך הממשק והעובד האמיתיים, או בבדיקה אוטומטית שמצוינת) ·
**דורש תיקון** (בעבודה מקומית מאושרת) · **חסום חיצונית** (תלוי בפעולה של הבעלים).

לא נפרס. פרסום והתראות אמיתיות כבויים. אישורים בבדיקות נעשו בידי שחקן בדיקה מסומן בלבד.
"נבדק" פירושו שהמסלול עבד ושמה שנמדד נמדד. זה אינו אומר שמישהו צפה או האזין: אף אחד לא עשה זאת.

עדכון אחרון: 2026-11-16.
