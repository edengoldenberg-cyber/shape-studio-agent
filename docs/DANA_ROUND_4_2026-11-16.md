## What the acceptance run showed, including what is NOT good

Both outputs ended with the verdict **"נדרש תיקון נוסף לפני צפייה"**. Each used all 4 review rounds (3 revisions,
about 18 minutes per output) and stopped with `no_progress`. The number of rounds was not raised.

### Findings that came back in every round

| Finding | What happened each round | Class |
|---|---|---|
| "אין הדגשה צהובה באף כרטיס" (blocking, reel and story) | The editor answered every round "נוספה הדגשה על N כרטיסים"; the code removed it every time because the approved test skill sets `highlight_enabled: false`. Neither the reviewer nor the editor is told that the skill switched highlighting off. | **Pipeline fault** — a finding that cannot be fixed burns every round |
| "הקאבר ריק ואין בו ציטוט" (blocking, story) | The editor answered "הקאבר הוגדר כציטוט…"; a story has no cover text by the target definition, so it stays empty. The reviewer is not told. | **Pipeline fault** (introduced with the story target) |
| Full-frame scene shows two lines ("לסמוך על" + "לסמוך על עצמי") (blocking, reel) | Caption cards keep running over the animation scene and repeat its text; the editor merged cards, which does not remove them from the scene. | **Pipeline fault** (captions are not suppressed or moved during a scene); in part a single mid-animation frame |
| Spelling "מאויימת / מאוימת" (blocking) | Fixed in round 1, back in round 2, fixed again in round 3. | **Editor fault** — a revision does not keep an earlier fix |
| 17 cards on screen for less than 0.5 s (advisory, reel) | 15–16 of the same findings in every round; the editor did not change them. The skill's mandatory "one line only" leaves little room to merge. | **Editor fault / rule conflict**, not decided |
| Opening title "נראית כקופסה אפורה ומכפילה את הכתובית" (advisory) | Wording changed between rounds while the frame did not. | **Unstable assessment** + a real question of taste |
