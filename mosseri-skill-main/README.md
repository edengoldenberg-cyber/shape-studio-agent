# מוסרי: ביקורת לכל ריל לפני שהוא עולה

סקיל ל-Claude Code שמעביר כל תוכן לאינסטגרם דרך 74 עקרונות שאדם מוסרי, ראש אינסטגרם, אמר בפומבי ב-12 החודשים האחרונים. כל עיקרון נשען על ציטוט מילולי קצר, עם תאריך וקוד של הפוסט המקורי.

שולחים לו תסריט, ריל מוכן, כיתוב, קאבר, קרוסלה או סטורי, ומקבלים תוך דקה ביקורת שאפשר לפעול לפיה מיד, ולא עוד "תחזקו את ההוק".

> ⚠️ **גילוי נאות:** הסקיל לא קשור לאינסטגרם, למטא או לאדם מוסרי, ולא אושר על ידם. הוא נשען רק על הפוסטים הציבוריים של מוסרי מ-29.10.2025 עד 26.10.2026, עם ציטוטים קצרים ומקור לכל אחד. מה שמוסרי לא אמר, הסקיל לא שם בפה שלו.

| דגלי סיכון | סימן מים של אפליקציה אחרת, תוכן ממוחזר, הבטחה שלא נפרעת |

## כמה זה מדויק? בכנות

בדקנו את המחוון בבדיקה עיוורת: סוכן ניקד 16 רילס של חשבון אחד בלי לראות שום מספר, ורק אחר כך השווינו לתוצאות האמיתיות.

- **חשיפה: הציון לא מנבא אותה.** המתאם היה 0.00. לכן הסקיל לעולם לא יגיד לך "זה יעשה 50K", וגם מוסרי עצמו אומר שאותו ריל יכול לקבל חשיפה שונה מאוד ביום אחר.
- **שיתופים: כאן כן היה קשר.** מתאם חיובי של 0.56 בין הציון לבין שיעור השיתוף (כמה אנשים שלחו את הריל ביחס לכמה ראו אותו). זה כיוון, לא תחזית מדויקת. וזה בדיוק האות שמוסרי אומר שהכי חשוב מול מי שלא עוקב אחריך.
- **המדגם קטן:** חשבון אחד, תחום אחד, 16 רילס. אצלך זה יכול להיראות אחרת, ובשביל זה יש כיול אישי.

הערך האמיתי הוא בתיקונים. ריל עם ציון נמוך ושלושה תיקונים טובים שווה הרבה יותר ממספר.

## התקנה

**הדרך הכי פשוטה: לתת לקלוד לעשות את זה.** פותחים את Claude Code ומדביקים:

> תתקין לי את הסקיל מהריפו https://github.com/Brain-ai-biz/mosseri-skill: תשכפל אותו לתיקייה זמנית, תעתיק את התיקייה mosseri אל ~/.claude/skills/mosseri, תריץ את cite_check.py על reference/doctrine.md ואת estimate.py עם ציון לדוגמה כדי לוודא שהכל עובד, ותגיד לי מה מצאת.

**או ידנית, ב-3 צעדים:**

1. **מורידים את הסקיל.** בטרמינל:
   ```bash
   git clone https://github.com/Brain-ai-biz/mosseri-skill.git
   ```
   בלי גיט: מורידים את קובץ ה-ZIP מעמוד ה-[Releases](https://github.com/Brain-ai-biz/mosseri-skill/releases/latest) ופותחים אותו.

2. **מעתיקים את התיקייה `mosseri` לתיקיית הסקילים של Claude Code.** לכל הפרויקטים:
   ```bash
   mkdir -p ~/.claude/skills && cp -r mosseri-skill/mosseri ~/.claude/skills/
   ```
   או רק לפרויקט אחד: לתוך `.claude/skills/` שבתיקיית הפרויקט.

3. **פותחים מחדש את Claude Code**, כותבים `/mosseri` או "תעביר את זה למוסרי", ומדביקים את התסריט או נותנים נתיב לקובץ הווידאו.

זהו. בלי מפתחות ובלי הרשמה.

## האם זה יעבוד אצלי?

- **צריך:** את Claude Code, ופייתון 3 (במק ובלינוקס הוא כבר מותקן). הסקריפטים משתמשים רק בספרייה הסטנדרטית.
- **מק, לינוקס, ווינדוס:** עובד בכולם. בווינדוס מעתיקים את התיקייה אל `%USERPROFILE%\.claude\skills\`.
- **כל שפה:** הביקורת יוצאת בעברית כברירת מחדל. כותבים לסקיל באנגלית, או מוסיפים ל-CLAUDE.md שלך את השורה `mosseri_lang: en`, ומקבלים אותה באנגלית.
- **כל תחום:** המחוון לא תלוי בנישה. המספרים בבדיקה העיוורת באו מחשבון בתחום ה-AI, ולכן הכיול האישי שימושי במיוחד בתחומים אחרים.

## תוספות (לא חובה)

- **פריימים מקובץ וידאו:** כדי שהסקיל יחלץ פריימים ויבדוק אזורי בטיחות צריך ffmpeg (במק: `brew install ffmpeg`). דף אזורי הבטיחות נוצר אם מותקן Pillow (`pip install pillow`).
- **תמלול אוטומטי:** רק עם מפתח OpenAI שלך, במשתנה הסביבה `OPENAI_API_KEY` (בערך חצי סנט לדקת וידאו, נשלחת רק רצועת השמע). בלי מפתח הסקריפט אומר את זה בעברית וממשיך, ופשוט מדביקים את התסריט. לעולם לא מדביקים מפתח בצ'אט.
- **כיול על החשבון שלך:** מייצאים את נתוני הרילס מ-Insights לקובץ CSV, והסקריפט `calibrate.py` בונה ממנו "מה רגיל אצלך". הכל נשמר רק אצלך, בתיקייה `~/.mosseri`. ההסבר המלא נמצא ב-`mosseri/reference/calibration.md`.
